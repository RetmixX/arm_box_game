      Высота проезда — на ней рука переезжает между лотком, клетками и стоянкой; фигурка в схвате не должна задевать другие. Цепочки начинаются и кончаются не ниже. Точки «по прямой» дробятся с шагом прямой: меньше шаг — ровнее, но медленнее.

      По расчёту для клеток и гнёзд без записанной цепочки

      Клетка — центр по геометрии поля, гнёзда 2–4 — поровну на прямой между гнездом 1 и 5. Рука приходит сверху на высоте проезда, опускается по прямой до высоты захвата, сжимает или отпускает схват и поднимается. Плитки гнёзд ставьте пластиной фигурки поперёк руки — схват подходит к каждому гнезду с одним поворотом.

      Порядок: «Над» — проверить центр клетки или гнезда; «Опустить» — схват на высоте захвата, губки должны охватывать пластину фигурки; затем «Закрыть схват». Высота −1 / +1 меняет высоту захвата сразу для всех клеток (или всех гнёзд); поправка — только для выбранной: вылет и база двигают руку над целью, высота опускает схват.

        Цепочки не обязательны: без цепочки рука ходит по расчёту (калибровка на вкладке «Настройка»). Цепочка нужна, если расчёт где-то не попадает. Гнездо: схват открыт → над фигуркой → вниз → закрыть → вверх. Клетка: с фигуркой над клеткой → вниз → открыть → вверх. Начните с «Черновика по расчёту» или опустите схват к фигурке и нажмите «Черновик отсюда». После партии руки проходят те же пути задом наперёд — проверьте «◀ Обратно».

        Клавиши: ↑ ↓ — вылет, ← → — база, PgUp / PgDn — высота, [ ] — поворот схвата, G — открыть / закрыть, с Shift шаг больше; Enter — точка, Shift+Enter — точка по прямой.

        Убрать фигурки

        Руки по очереди вернут фигурки с поля в свои лотки. Уберите руки от стола. Если уже разложили фигурки по гнёздам сами — выберите «Убрал сам».
