# Протокол устройств

Как фронт общается с backend руки, лампой и камерой. Собрано по `web/assets/driver.js` и `app.js`; источник истины — backend на руке (`main.py`).

## Backend руки (FastAPI, порт по умолчанию 8000)

CORS на рабочих руках настроен — страницы обращаются напрямую `http://IP:порт`. Для разработки есть прокси `serve.py` и nginx-конфиг (в репозиторий не попали; фронт их определяет запросом `GET /__backend`).

| Метод | Путь | Тело / ответ |
| --- | --- | --- |
| GET | `/api/motors/pos` | `[{"1": 2048}, {"2": 2051}, …]` — позиции серво 1–6, тики |
| GET | `/api/motors/temp` | то же, °C |
| GET | `/api/motors/load` | то же; биты 0–9 — величина 0…1023, бит 10 — направление |
| POST | `/api/motors/pos/set` | `{x, z, angel, pov_gripper, gripper_state}` → ответ после завершения движения |
| WS | `/ws` | `{"command": "exec", x, z, angel, pov_gripper, gripper_state}` → `{"status": "ok"}` или `{status, message}` |
| GET | `/api/motors/speed` | `{"speed": 30}`, % — **только с патчем `backend-patch`**, иначе 404 |
| POST | `/api/motors/speed` | `{"speed": 1…100}` — то же |

Команда движения:

| Поле | Тип | Смысл |
| --- | --- | --- |
| `x` | int, мм | вылет середины схвата от оси базы |
| `z` | int, мм | высота середины схвата над низом базы |
| `angel` | int, ° | поворот базы, 180 = центр (позиция 2048). Опечатка в имени — как в backend |
| `pov_gripper` | int, ° | поворот схвата, 1…300; мотор 5 = `ceil(pov × 3.41)` |
| `gripper_state` | bool | мотор 6: `true` → 370, `false` → 710. Открыт это или закрыт — настройка (`gripTrue`) |

Pydantic принимает только целые — фронт округляет (`Driver.normalize`). Для рисования маркером это даёт ступеньку 1° по базе (~3,5 мм на вылете 200 мм); дробный `angel` в backend сделал бы линии ровнее (см. backlog).

WS-ответы не содержат id и приходят строго по порядку отправки — `RealDriver` сопоставляет их очередью FIFO. Обрыв WS → все ожидающие команды отклоняются, переподключение с экспоненциальной задержкой до 10 с.

Недостижимая точка → backend бросает `ARMIKError` (HTTP-ошибка / `status != ok`).

## Лампа (порт 80)

`PUT http://IP/api/lamp` с телом `{"red": bool, "yellow": bool, "green": bool, "blue": bool}`. По умолчанию IP лампы = IP руки. В игре у каждой руки своя лампа.

## Камера (порт по умолчанию 8080)

| Метод | Путь | |
| --- | --- | --- |
| POST | `/api/start` | включить |
| POST | `/api/stop` | выключить |
| GET | `/api/status` | формат заранее неизвестен — `Driver.cameraRunning()` понимает частые варианты |
| GET | `/stream` | MJPEG, вставляется в `<img>` |

В игре камера только показывает лист участникам; распознавания нет.
