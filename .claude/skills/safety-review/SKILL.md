Изменения:

```!
git status --short
git diff HEAD --stat
```

Проверь дифф (`git diff HEAD`) по пунктам из раздела «Правила, которые нельзя нарушать» в `CLAUDE.md`:

- каждая точка перед отправкой проходит `Kin.inWorkZone` (x ≥ 120, угол 30…330, z в пределах `Kin.WORK`);
- новая команда руке уходит только после завершения предыдущей; в игре — только через `enqueue()`;
- в backend уходят целые (`Driver.normalize`), имена полей как в API (`angel`);
- телеметрия опрашивается последовательно;
- при обрыве связи, таймауте или ошибке UI не считает движение выполненным и показывает человеку понятную причину;
- нет запросов к реальным адресам из тестов и скриптов.

Ответ: список находок «файл:строка — что не так — как исправить», от опасных к косметике. Нет находок — так и скажи.
